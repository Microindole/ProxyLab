## 通用要求

- 只在授权设备、授权网络和授权服务器上运行。
- 不采集私人账号、密码、Cookie、令牌、私信或敏感业务数据。
- 不运行高并发爬虫、压力测试、验证码绕过或异常下载。
- 原始 PCAP 不提交到 Git，不对外公开分享。
- 每批数据保留采集命令、目标类别、口径说明和 `capture.json`。
